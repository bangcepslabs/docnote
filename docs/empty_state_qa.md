# 빈 상태 화면 접근성 보완

2026-10-21

- 검색 대기 화면을 공통 EmptyState로 통합했다.
- 높이가 부족하면 안내 전체를 스크롤할 수 있다. 키보드/가로 화면에서 고정 Column이 넘치는 문제를 방지한다.
- 설명 영역은 최대 420dp로 제한하고 제목도 가운데 정렬한다.
- 검색 조건, 데이터, 저장, Home 정보 구조, 툴바는 변경하지 않았다.

## 검증

- flutter analyze: 통과.
- flutter test: 전체 41개 통과.
- Android x64 Debug APK 빌드 성공 (145.8초). 기존 KGP 호환성 경고는 남아 있다.
- 새 위젯 테스트: 320×160, 1000×700, 글자 200%, Light/Dark에서 overflow 없음.
- 스크롤하여 설명문에 도달할 수 있는지 확인.

이번 기록은 공통 빈 상태 컴포넌트 검증이며 전체 앱 검증 완료를 의미하지 않는다.
