# 앱 회귀 검증 — 2026-10-22

## 발견 및 수정

1. Home: 320dp / 글자 130%에서 라이브러리 제목·정렬·보기 전환 행이 56px overflow.
   - 좁은 폭 또는 큰 글자에서는 정렬 아이콘과 기존 메뉴를 사용한다.
   - 제목은 가용 폭 안에서 한 줄로 표시한다. 섹션 순서와 정렬 기능은 유지.
2. 생성 메뉴: 큰 글자에서 새 노트 Hero의 고정 높이 때문에 6px vertical overflow.
   - 최소 높이는 유지하고 실제 내용에 맞게 늘어나도록 수정.
   - 설명문을 자르거나 글자를 강제 축소하지 않는다.
