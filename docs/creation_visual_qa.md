# 생성 화면 시각 품질 검증

2026-10-20~21 · Pixel 7 / Pixel Tablet

## 변경 내용

- 새 노트 제목 입력창의 중첩 배경과 이중 테두리를 단일 입력 표면으로 통합.
- 표지·속지의 간단 선택 및 전체 보기에서 `_NotebookChoiceTile` 공유.
- 전체 보기의 외곽 카드 제거. 표지/종이 아래에 제목과 보조 정보를 배치.
- 선택 테두리와 체크 표시는 160ms로 전환하며 동작 줄이기 설정을 존중.
- 다크모드의 선택 칩·보조 텍스트·배경을 공통 색상 토큰으로 변경.
- primary 버튼의 글자 색상을 흰색으로 명시하여 다크모드 대비 확보.
- 다크모드 텍스트 버튼은 밝은 blue 계열 토큰을 사용해 surface와 4.5:1 이상 대비 확보.
- 작은 미리보기는 기존 compact 표지 renderer를 사용해 큰 글자에서 overflow 방지.
- 새 노트 화면의 미리보기 높이와 섹션 간격 축소.
- 전체 보기 진입 전 제목 입력 포커스를 해제.
- 실제 표지 색상과 다른 `work`, `study` 표시 이름 수정. 저장 ID는 동일.
- 생성 메뉴의 장식 패턴을 표지 미리보기 경계 안으로 제한.

PDF 빈 파일 검사 테스트에서 발견한 비동기 race도 정리했다. 파일 검사 Future를 기다린 뒤 임시 파일을 제거한다. 제품 PDF 로직은 변경하지 않았다.

이 기록은 생성 화면 변경의 검증 범위다. 앱 전체의 실기기 필압·장시간 성능 또는 모든 기능이 완전히 검증되었다는 의미는 아니다.
