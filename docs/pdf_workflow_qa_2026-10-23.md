## 재현한 결함

PDF에서 펜 두 획을 작성했으나 화면에는 나타나지 않았다. 주석 JSON에는 두 획이 저장되었고 내보낸 PDF에도 정상 합성되었다.

원인: `PdfPageWithInk`가 mutable strokes/active 배열을 갱신하면서 공통 `DrawingCanvas`의 revision을 기본값 0으로 두고 있었다. 공통 painter의 변경 감지 계약과 PDF 호출부가 불일치했다.

수정: PDF adapter에서 active revision을 빌드마다 전달하고 committed revision은 로드, 변경 저장 예약, 올가미 이동 시 갱신한다. 저장 포맷/필기 알고리즘/노트 툴바는 변경하지 않았다.
