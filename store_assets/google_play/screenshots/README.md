# Google Play screenshots

Captured from the current Android profile build on clean, isolated Pixel 7 and Pixel Tablet QA emulators. The demo notebooks and imported HWP file exist only on those QA emulators; existing development emulator data was not used.

## Phone

1080 × 2160 JPEG (portrait)

1. `phone/01-home-library.jpg` — Home library with notebook covers and an HWP first-page preview.
2. `phone/02-notebook-editor.jpg` — Notebook editor with the writing toolbar and sample text.
3. `phone/03-hwp-document.jpg` — HWP document viewer with page navigation.
4. `phone/04-search-results.jpg` — Search results for a notebook.

## Tablet

1920 × 1200 JPEG (landscape, 16:10)

1. `tablet/01-tablet-home.jpg` — Tablet Home with recent documents and library.
2. `tablet/02-tablet-documents.jpg` — Two-column Documents library with HWP and notebook previews.
3. `tablet/03-tablet-notebook-editor.jpg` — Notebook editor with a sample diagram and toolbar.
4. `tablet/04-tablet-search.jpg` — Tablet search results.

These are unframed emulator captures saved as JPEG at quality 95. The phone set is 9:18 and the tablet set is 16:10. Review the tablet captures in Play Console preview as well, since Android's tablet system navigation indicator is visible in the raw device screenshots.
